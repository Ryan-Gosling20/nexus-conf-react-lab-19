# NEXUS CONF — React UI

Учебный проект для лабораторной работы №19. Интерфейс лендинга IT-конференции реализован на React по макету из лабораторной работы №17.

## Реализованные компоненты

- `Button` — переиспользуемая кнопка с вариантами оформления и обработчиком `onClick`.
- `SpeakerCard` — карточка спикера; все данные передаются через `props`.
- `Accordion` — интерактивный FAQ; состояние открытого/закрытого элемента хранится в `useState`.

Компоненты являются функциональными, используют JSX и `PropTypes`. Стили изолированы с помощью CSS Modules.

## Запуск проекта

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Проверка сборки

```bash
npm run lint
npm run build
```

Готовая production-сборка будет создана в каталоге `dist`.
